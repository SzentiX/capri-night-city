# Validation and runtime limits

Version 1.9.4 separates the game-side source/download from the Capri mod directory submission and scopes unprefixed commands to a live loaded game link. Explicit `night city` commands remain available offline. It adds no gameplay mechanics. This checkout and its build fixtures are separate from the installed game and Capri files.

The 8 November 2026 build passed **222 game-side mocked checks** and **289 Capri/protocol checks** (511 total), including real-file C#/Lua cross-process fixtures, Lua syntax checks and guarded installation/rollback fixtures. The C# mod compiled against installed Capri **0.8.6.1**. The new command-ownership regressions cover all seven reported phrases, polite variants, explicit namespaces, the actual `Heard` return value and absence of speech/writes while disconnected, stale/future heartbeats, no loaded save, menus, absent session and a contended polling lock. Public setup tests preserve an existing selection and avoid writing a fake game directory. `Build.ps1` reproduces these checks; installed-Capri compilation is optional when that executable is absent.

The directory PR contains only the `.capri-code` client, README and preview. The CET-only release, Lua, optional PowerShell utilities and test source live in this external repository and have not been checked by the Capri mod directory reviewers. The release ZIP includes six bridge files, a manual installation guide and SHA-256 checksums; it contains no PowerShell scripts or Capri client.

The resource review bounded kill history (1,024 IDs), recent events (24), replay IDs (256), counter-victim IDs (128), report queue (3), recent spoken lines (4), pending UI report (1), pending command (1) and independent brain calls (1 per process/AppDomain). Cleanup retries are bounded and do not replay irreversible damage. Stop avoids the polling lock, publishing uses unique temporary files and lease cleanup checks ownership. Dashboard timers/fonts have explicit disposal.

The internal `Brain.Aside` API exposes no cancellation handle. One detached provider call may remain until completion or provider timeout; the shared budget prevents repeated mod reloads from multiplying it. Capri's .NET Framework loader retains compiled assemblies in its default application domain until Capri exits. Restart Capri after repeated code-mod edits. See [Microsoft's assembly unloading documentation](https://learn.microsoft.com/en-us/dotnet/standard/assembly/load-unload).

Automated checks are **not live gameplay, microphone, native HUD/effect validation or heap/CPU profiling**. Incoming hack cancellation, silent death/witness behavior, vehicle destruction, scanner outlines, provider/audio behavior and compatibility with other game mods still need live testing. No leak-free or flawless-gameplay claim is made.
